# Проект "Торговая сеть электроники"
## Описание:
Данный проект является back-end версии для платформы для торговой сети электроники
## Содержание:
* модуль manage.py в корне проекта
* директория config
* директория network
* директория users

Права доступа настроены так, чтобы только активные сотрудники могли иметь доступ к API.

Для JWT-авторизации использован djangorestframework-simplejwt.

### Запуск проекта:
1. Склонируйте репозиторий
```
git clone git@github.com:knewtr/electronics_sales.git
```
2. Установите и активируйте виртуальное окружение и зависимости
```
pip install -r requirements.txt
```
3. Создайте файл .env в корне проекта и добавьте в него переменные окружения аналогично файлу .env.sample
4. Примените миграции
```
python manage.py migrate
```
5. Создайте суперпользователя
```
python manage.py csu
```
6. Запустите сервер с помощью команды
```
python manage.py runserver
```
После запуска приложение будет доступно по этому адресу http://127.0.0.1:8000/

Для добавления объектов воспользуйтесь административной панелью Django (http://127.0.0.1:8000/admin/)
Также с помощью admin-action можно обнулять задолженность звена.

### Применение API
Подробнее можно узнать по ссылке: http://127.0.0.1:8000/swagger/
